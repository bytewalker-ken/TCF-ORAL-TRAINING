# TCF Québec Oral Lab V4

一个面向 TCF Québec 口语备考的静态 GitHub Pages 学习网站。

## 学习逻辑
- 🟣 题型 / 母题：先判断题目属于哪一类。
- 🟢 万能句：跨多个主题都能直接复用；不限定14句，持续扩充。
- 🔵 半通用句：句型基本固定，只按题目替换少量关键词。
- 🟠 本题具体内容：范文中必须随题目变化的内容，不需要用户填写。

## 当前内容
- 130 道题：Tâche 2 60 道、Tâche 3 70 道
- 17 个母题
- 46 句扩展万能句
- 每个母题都有 Tâche 2 / Tâche 3 的近万能范文版本
- 每一道题都有完整范文和颜色拆解
- 浏览器本地保存完成题和错题

## GitHub Pages
将整个文件夹上传到 GitHub repo，然后在 Settings → Pages → Deploy from a branch → main / root。

> 题目资料来自公开的考生回忆/整理题库，不应视为官方公开原卷。网站范文为学习用途的原创参考答案。
